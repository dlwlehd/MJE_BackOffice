# 엠제이 운영 관리 · 공유용 데모

Figma v3의 MJE 보라색과 shadcn/ui 구성을 실제 React 화면으로 구현한 체험 사이트입니다.

## 실행

```sh
npm ci
npm run dev
```

## 구현한 기능

- 학사 일정: 월간/12개월 보기, 기간 일정, 분류·학교·제목 필터, 등록·수정·삭제, 모바일 날짜별 목록.
- 토요 보강: 교시별/전체 목록/학습 시간/완료/날짜 미정 보기, 토요일 및 30분 단위 검증, 중복 예약 검사, 출석·학습 결과, 주간 보관 후 보강만 초기화, 인쇄.
- 상담: 주간 목록/전체 이력, 유형·담당자·검색 필터, 신규 대상 및 재원생 전환, 예약·취소·미방문, 결과 임시 저장/완료, 대상자별 누적 기록, 후속 예약, 수정 이력.
- 공통: 브라우저별 데모 저장, 다른 탭 갱신, JSON 내보내기, 샘플 초기화, 모바일 메뉴와 편집 패널.

## 저장 경계

가상 학생과 가상 상담 기록만 포함합니다. 실제 DB·로그인·직원 권한·다른 기기 동기화는 없습니다. `localStorage`의 `mje-academy-demo-v1` 키에 해당 브라우저의 수정 내용만 저장합니다. 초기화하면 해당 브라우저 데이터만 샘플로 바뀝니다. 실제 개인정보는 입력하지 마세요.

`lib/demo-repository.ts`를 향후 인증된 API 어댑터로 교체합니다. 현재 입력 검증은 클라이언트 체험용이며, 운영 전 동일 검증 및 권한·경합 방지를 서버에서 구현해야 합니다. 정기 유형은 초기화 시 유지하지만 다음 주 자동 편성은 구현하지 않았습니다.

## 검증

```sh
npx tsc --noEmit
node --experimental-strip-types --test tests/domain.test.ts
```

배포는 Sites에 연결되어 있으며 `.openai/hosting.json`은 DB 바인딩 없이 설정했습니다. 실제 DB 연결 및 비용 결정은 후속 단계입니다.
