# MJE 공유용 데모 구현

2026-09-21. 사용자의 최종 지시에 따라 실 DB 연동을 미루고 샘플 데이터 기반 데모를 배포한다.

운영 데이터 이관, 로그인/직원별 권한, 실시간 직원 간 동기화, 정기 수업 자동 생성, 실제 연락처 관리, 자동 백업은 후속 범위다. 주간 보관, 신규 학생 등록 전환, 상담 누적 결과는 데모에서 체험할 수 있다.

## 다음 DB 연동 시 검토

이번 배포는 외부 DB를 생성하거나 결제하지 않는다. 무료 DB 후보는 다음 단계에 실제 직원 수·데이터 보존 기간·인증 방식을 확인하고 선택한다.

- Cloudflare D1: 공식 무료 한도는 일 500만 행 읽기, 10만 행 쓰기, 총 5GB. SQLite 기반으로 작은 학원 운영 데이터에 적합한 후보다. Sites의 관리형 리소스 요금과 본인 Cloudflare 계정 무료 요금은 동일하다고 가정하지 않는다. https://developers.cloudflare.com/d1/platform/pricing/
- Supabase: 무료 DB 500MB, 낮은 활동이 7일 지속되면 프로젝트 일시 중지 가능. 인증·Postgres가 필요한 경우 비교한다. https://supabase.com/pricing 및 https://supabase.com/docs/guides/platform/free-project-pausing

연동 시에는 공유된 운영 DB와 외부 공개 데모를 분리하고, 서버 권한 검사·토요일/시간/중복 검증·감사 이력·버전 충돌·백업부터 갖춘다. 운영 환경을 공개 체험 모드로 전환하지 않는다.

## 확인 결과

- TypeScript 검사 및 구현 파일 ESLint 통과.
- 날짜·중복·완료 조건의 도메인 테스트 6개 통과.
- Chrome에서 일정 저장 및 새로고침 유지, 연도 경계 일정, 12개월 보기 확인.
- 상담 결과 완료 후 이전 결과가 유지되고 누적 이력에 표시됨을 확인.
- 보강 평일 예약 거부, 결과 저장 시 출석이 자동 변경되지 않음 확인.
- 6건 주간 스냅샷 보관 후 정기 1건만 현재 목록에 유지됨 확인.
- 390px 모바일 달력·상담 및 360px 입력 패널의 가로 넘침 없음 확인.
- 독립 브라우저 방문자의 데이터가 서로 분리됨을 확인.
- 브라우저 실행 오류 0건. 배포용 빌드 완료.

이 검증은 데모 입력 흐름에 한정한다. 운영 DB, 보안, 권한, 다중 직원 동시 수정, 복구 가능 삭제는 실제 운영 연동 단계에서 검증해야 한다.

## 2차 개선

- 달력의 시간 일정·기간 일정에 HoverCard 요약 추가. 클릭 편집은 유지.
- 토요 보강 상단에 날짜별 담당 선생님 순서 표시와 이름 필터 추가.
- 상담 예약/결과/누적 이력 편집을 중앙 Dialog로 변경. 모바일은 화면 안에서 높이를 제한하고 본문만 스크롤.
- 예약 파랑, 완료 초록, 취소 보라, 미방문 빨강, 미기록 주황 적용.
- 사이드바 학년도 및 보강 운영 시간 문구 제거.
- 보강 스케줄 메뉴: 토요일별 선생님 추가/제외, 드래그와 위아래 이동, 저장, 월별 배치 확인. 변경은 학생별 예약 담당자에 영향을 주지 않음.
- v1 브라우저 데이터에 teacherSchedules가 없어도 기존 데이터를 유지하며 읽음.

검증: 도메인 검사 8개, TypeScript·ESLint, 실제 Chrome의 hover·중앙 편집 저장·드래그·날짜별 배치·새로고침 보존·360px 모바일 검사 통과. 브라우저 실행 오류 없음.

## 3차 개선 — 운영 방식 정정

2차 개선의 날짜별 다중 교사 배치 방식은 폐기한다. 토요일 하루를 한 교사가 담당하며 시작일과 교사 순서로 매주 순환한다. 새 규칙 이전 배정과 보관 스냅샷은 유지하고 기존 브라우저 기록은 초기화하지 않는다. 학생 보강의 담당자 선택을 제거하고 당일 담당을 자동 표시한다.

상담 예약 옆에 바로 상담 일지 작성 버튼을 추가한다. 같은 중앙 창에서 대상·일시와 기록을 입력하며 임시 저장은 작성 중, 완료는 기록 완료로 표시한다. 실제 상담 일지는 예약 슬롯을 생성하지 않는다. 학사 일정 담당자는 미지정 선택으로 해제한다.

검증: 도메인 테스트 9개, TypeScript·ESLint 통과. Chrome에서 미지정 저장, 기존 기록 보존, 주간 교대, 새 규칙 이전 배정 유지, 일지 임시 저장·완료·재접속 보존, 360px 상담 창 확인. 브라우저 실행 오류 0건.

## 4차 개선 — 당일 대체와 선생님 등록

토요 보강 상단에서 특정 토요일만 담당 교사를 변경하고 기본 로테이션으로 복원할 수 있다. 다음 주 순환과 보관 기록은 유지한다. 보강 스케줄에서 선생님을 등록하면 일정·상담·로테이션·당일 대체 담당자 목록에서 선택 가능하다. 실제 로그인 계정을 생성하지 않는다.

도메인 테스트 10개 및 TypeScript·ESLint·배포 빌드 통과. Chrome에서 등록, 모든 담당자 선택 목록 반영, 당일 변경, 재접속 보존, 다음 주 유지, 기본 배정 복원, 모바일 가로 넘침 없음 확인. 공유 데모 배포 완료.
