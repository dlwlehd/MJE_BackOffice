## 변경 방향

반복되는 상단 메뉴와 큰 버튼 묶음을 제거하고 왼쪽 사이드바로 주 탐색을 이동했다. 상단에는 현재 위치만 표시하고 본문에 제목·주요 작업·도구 모음을 배치했다. 기존 v2 및 BackOffice 페이지는 수정하지 않았다.

- 사이드바 232px, 현재 위치 영역 56px, 본문 여백 32px.
- 기본 컨트롤 36px, 모바일 주요 작업 44px. 본문 14px, 보조 정보 12–13px, 페이지 제목 26px.
- 흰 배경과 중립색 경계선, MJE 보라색 주요 버튼. 시험은 청색, 방학은 청록, Test는 보라색으로 구별한다.
- 등록·수정은 오른쪽 520px 패널, 삭제 확인은 중앙 대화상자에 배치한다.
- 모바일은 사이드바를 메뉴로 접고 날짜 아래 일정 목록 또는 단일 열 입력을 표시한다.

## 라이브러리 대응

[shadcn Sidebar](https://ui.shadcn.com/docs/components/base/sidebar), [Button](https://ui.shadcn.com/docs/components/base/button), [테마 토큰](https://ui.shadcn.com/docs/theming)을 참고했다. 연결된 Figma 라이브러리에서 shadcn 자산을 찾지 못해 로컬 디자인 컴포넌트를 만들었다. 공식 Figma 키트를 가져왔거나 실제 React 패키지를 설치한 결과는 아니다.

| 디자인 요소 | 구현 시 대응 |
|---|---|
| 좌측 탐색 / 현재 위치 | Sidebar, Breadcrumb |
| 주요·보조·약한 강조·위험 버튼 | Button variants |
| 보기 전환 | Tabs |
| 상담 / 보강 / 보관 목록 | Table 또는 Data Table |
| 날짜·시간·담당자 | Field, Select, Popover + Calendar |
| 긴 상담 기록 | Textarea |
| 유형 / 상태 | Badge |
| 오른쪽 등록·편집 패널 | Sheet |
| 삭제 확인 | Alert Dialog |

월간 이벤트 격자는 업무용 별도 구성이다. shadcn의 [Calendar](https://ui.shadcn.com/docs/components/base/calendar)를 학원 일정 관리 기능 전체로 오해하지 않는다. 날짜 선택에 사용하고, 기간 일정·이벤트 표시·연간 요약은 별도 업무 로직으로 구현한다.

## 대표 검토 흐름

1. 월간 → 12개월 → 9월 → 월간. 시험 일정 → 편집 패널 → 삭제 확인/취소. 일정 만들기 → 신규 패널 → 저장 화면 이동.
2. 보강 → 교시별/전체 목록/학습 시간/보관함. 박은서 카드 → 출석·결과 패널. 보강 등록 → 신규 패널.
3. 상담 → 결과 작성 → 결과 저장 → 완료 목록 → 저장된 기록. 이전 기록은 8월 24일 사례를 연결했다.
4. 모바일 메뉴 → 상담 목록 → 박은서 결과 작성 → 저장 완료 목록.

저장 버튼은 대표 화면으로 이동하는 프로토타입이다. 실제 데이터 저장·삭제는 실행하지 않는다. 다른 날짜와 모든 학생의 상세, 검색·필터 계산, 입력값 변경, 예약 충돌 계산, 정기 편성·초기화·복원 상세, 인쇄와 권한 처리는 개발 및 후속 상세 설계 범위다. 기능 요구사항은 [기능 명세 v2](site-functional-spec-v2.md)를 유지한다. 별도 화면을 그리지 않은 기능을 삭제한 것으로 해석하지 않는다.

## 검증

전체 업무 프레임의 경계 초과, Noto Sans KR 글꼴 일치, 이동 대상의 존재와 새 페이지 내 연결을 검사했다. 월간·보강 현황의 세로 넘침을 조정하고, 입력 텍스트가 필드 너비 전체를 쓰도록 수정했다. 주요 데스크톱·모바일·편집 패널을 렌더링해 확인했다.

일반 글자와 상태 배지의 대표 전경/배경 대비를 계산했다. 보조 글자와 연한 회색 배경의 대비가 4.40:1인 조합을 발견해 보조 글자색을 더 진하게 조정했다. 이 검사는 실제 웹 접근성 전체 검증을 대신하지 않는다.

실제 웹의 키보드 접근, 모바일 가상 키보드, 화면 읽기, 반응형 동작, 저장 실패·권한·동시 수정 처리는 구현 후 별도 검증한다. 가상 데이터의 보강 날짜는 토요일로 유지하며, 토요일 제약과 30분 단위 검증은 서버에서도 적용한다.

## MJE 브랜드 색 반영

기본 배치는 유지하면서 주요 버튼·로고·오늘 날짜·학습 시간 그래프에 브랜드 보라색 `#5B3FD6`을 적용했다. 선택 메뉴와 탭은 연보라색 `#ECE6FF` 배경에 진한 보라색 `#35216F` 글자를 사용한다. 사이드바는 `#FAF9FD`로 옅게 물들이고, 연간 달력의 현재 월 테두리도 브랜드 색으로 통일했다. 시험·방학·위험·완료 상태의 의미별 색은 유지한다. v3 전용 토큰을 수정했으며 기존 페이지의 브랜드 컬렉션은 변경하지 않았다.
