## 작업 범위

기존 `MJE · 첫 번째 디자인`, `Pages - Phase 1`은 보존했다. **Pages - 일정 통합 v2** 페이지를 새로 생성하고 기존 보라색 브랜드 변수·Noto Sans KR·Simple Design System 버튼과 입력 인스턴스를 참고해 화면을 새로 구성했다. 기존 업무 화면을 통째로 복제하지 않았다.

관리 화면에 맞춰 디자인 변화 3, 움직임 2, 정보 밀도 6으로 정했다. 사용자가 지정한 design-taste-frontend의 가독성·대비·일관성 원칙을 적용했다. 해당 스킬의 랜딩 페이지용 사진·히어로·스크롤 애니메이션 규칙은 이 관리 도구에 적용하지 않았다.

## 프로토타입 검토 순서

1. 시작 안내 → 토요 보강 → 보강 등록 또는 학생 상세·결과 → 보강 저장으로 현황 복귀. 전체 목록·학습 시간 그래프·완료/보관함 전환 확인.
2. 학사 일정 → 12개월 보기 → 9월 선택 → 월간 → 9월 14일 또는 일정 등록 → 편집 → 저장/취소로 월간 복귀. 삭제는 확인 화면까지 검토.
3. 상담 일정 → 상담 예약 → 예약 저장으로 목록 복귀 → 결과 기록 열기 → 누적 이력 및 후속 상담 예약 확인.

대표 화면 사이의 이동만 구현했다. 저장 버튼의 이동은 실제 저장을 의미하지 않는다. 입력·선택·필터·날짜 변경·삭제 확정·인쇄·실시간 동기화·권한 검사는 구현 전이다. 결과 완료 뒤 성공 상태, 예약 취소·미방문 상세, 정기 등록 관리·샘플 복원 상세 도구는 기능 명세에 포함했으며 세부 상태 디자인은 후속 작업이다. 모바일은 주요 조회 화면안이며 모바일 입력·편집 전체 흐름은 아직 연결하지 않았다.

## 시각 검증

각 업무 화면과 모바일 화면을 렌더링해 확인했다. 월간·연간의 주요 버튼 표시와 대비, 상담 목록의 보조 버튼 글자색, 긴 보강 현황판의 하단 잘림을 수정했다. 새 페이지의 텍스트는 Noto Sans KR로 통일했고 공통 브랜드 변수에 바인딩했다. 원본 화면의 인물·상담·진행 내역은 디자인에 복사하지 않았으며 모든 표시 데이터는 가상 예시다.

최종 검사: 17개 프레임, 화면 이동 연결 79개. 검사한 부모 영역 경계 초과 0개, 글꼴 불일치 0개, 존재하지 않는 이동 대상 0개. 검사 결과와 실제 웹의 접근성·저장·반응형 검증은 별개다. 최종 검토는 실제 사용자의 운영 순서와 미확정 정책을 확인한 후 진행한다.

## 원본 사이트 조사 범위

[토요 보강 실시간 현황판](https://sat-tutoring-krxbzcsy.manus.space/)의 등록 양식·전체 목록·수정 창·시간 그래프·주간 보관함 상세를 직접 확인했다. 초기화·삭제·샘플 복원·저장·인쇄는 실행하지 않았다. 초기화 안내와 버튼 존재를 실제 처리 결과로 간주하지 않았다.

## 2026-09-21 구글 캘린더 참고 개선

[개선된 월간 달력](https://www.figma.com/design/TylS0VlSfrVVEFoYjl5Xlg?node-id=133-1532).

구글의 [보기 전환·일정 구분 안내](https://support.google.com/a/users/answer/9323423?hl=en)와 [Calendar 제품 페이지](https://workspace.google.com/products/calendar/)를 참고했다. 구글 서비스 연동이 아닌 화면 구성 개선이다. 엠제이 브랜드 색과 기존 컴포넌트를 유지한다.

- 상단에 오늘·이전·다음, 연월, 월간/12개월 보기와 검색을 모았다.
- 왼쪽에 등록 버튼, 미니 달력, 일정 분류 체크 필터와 학교 필터를 배치했다.
- 월간 격자를 넓히고 주말 배경, 이전/다음 달 날짜, 오늘 날짜 원형 강조를 적용했다.
- 종일·기간 일정은 여러 날짜를 잇는 막대로 표시한다. 주가 바뀌는 기간은 다음 행에서 이어짐을 표시한다.
- 시간 지정 일정은 시각과 제목을 표시한다. 9월 21일은 2건을 표시하고 +2개 더 보기에서 전체 4건을 확인하는 시안이다.
- 모바일은 일정이 있는 날짜 표시와 선택일 시간순 목록을 추가했다. 오늘 강조는 예시 기준일 2026-09-21이다.

추가 화면: [일정 상세 팝업](https://www.figma.com/design/TylS0VlSfrVVEFoYjl5Xlg?node-id=141-2101), [하루 일정 펼침](https://www.figma.com/design/TylS0VlSfrVVEFoYjl5Xlg?node-id=141-2515). 현재 총 19개 프레임이다. 위의 17개/79개는 개선 전 검증 기록이다.

연결: 월간의 매탄중 시험일 → 상세 → 수정/삭제/닫기, +2개 더 보기 → 하루 일정 펼침 → 닫기. 날짜 이동·검색·체크 필터는 표시 상태이며 실제 데이터 동작은 구현 전이다. 12개월 화면은 기존 연간 계획 보기를 유지했다.

## 2026-09-21 유사 서비스 점검 반영

[점검 문서](design-reference-review-2026-09-21.md)의 개선 방향을 기존 v2 페이지에 반영했다. 원본 BackOffice 페이지는 변경하지 않았다.

- 상담 목록: 행별 대상자·유형·담당·상태·작업을 정렬하고 결과 미기록을 강조했다. 4명의 예약 상세와 박은서 결과 작성으로 각각 연결한다.
- 상담 기록: Simple Design System의 Textarea Field를 사용해 여러 문단을 표시한다. 후속 조치의 내용·담당자·기한을 분리하고 이전 기록·저장 완료·저장 후 목록으로 연결했다.
- 상담 예약: Select Field와 Date Picker Field를 적용하고 시작/종료 시간을 분리했다. 시간 충돌은 겹치는 상담과 변경 방법을 표시하는 별도 상태로 연결했다.
- 보강: 담당자와 출석/결과 상태를 카드에 표시하고 출석 미확인·결과 미기록 필터를 추가했다. 고유 학생 6명과 교시 배정 11건을 구별한다. 박은서 카드에서 상세로 진입한다. 과밀 주의는 기존 주의 색 변수를 사용한다.
- 연간 계획: 날짜 글자를 10px에서 12px로 조정하고 일정 날짜 표시·월별 주요 기간·미등록 월 안내를 추가했다. 월별 요약은 14px로 표시한다. 9월을 선택하면 월간 화면으로 이동한다.
- 공통: 현재 메뉴를 브랜드 채움으로 강조하고 비활성 메뉴는 단순화했다. 방학은 녹색 문구, 시험은 진한 보라, Test는 브랜드 보라와 유형명으로 구별한다. 별도의 청색 시험 토큰은 추가하지 않았다.
- 삭제/초기화: 보강 더보기에서 초기화 확인으로 진입한다. 학사 일정 삭제와 학생 보강 삭제는 각각 대상과 범위를 표시하는 별도 화면으로 분리했다. 실제 확정 동작은 연결하지 않았다.
- 모바일: 상담 목록 → 박은서 결과 작성 → 저장 완료 → 완료 목록의 대표 흐름을 추가했다.

### 검증 및 남은 구현 범위

36개 프레임을 구조 검사했다. 검사 시점의 이동 연결 200개에 누락 대상이 없었고, 부모 경계 초과와 Noto Sans KR 불일치도 없었다. 이후 시작 안내에 모바일 진입 링크 1개를 추가했다. 상담 목록·본문·예약·중복 상태·보강·연간·월간·모바일 작성/목록을 렌더링해 확인했다. 여러 줄 입력의 초기 잘림은 전용 Textarea 컴포넌트로 교체해 수정했다.

대표 데이터로 연결한 Figma 프로토타입이며 실제 필터 계산·입력·저장·삭제·동기화는 구현되지 않았다. 다른 학생의 보강 상세, 모든 월 이동, 모바일 예약·이력 탐색 전체는 아직 시연 범위 밖이다. 모바일 상담 예약 버튼은 데스크톱 예약 시안으로 연결된다. 키보드 표시·실제 터치·접근성 전체 검증은 구현 후 필요하다. 초기화의 실제 처리 범위는 기존 명세의 운영 정책 확인 항목을 유지한다.
